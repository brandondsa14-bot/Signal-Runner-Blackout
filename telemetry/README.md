# CP5 Telemetry

Press `F9` during gameplay to write a CSV snapshot.

- BEFORE profile: `latest_before.csv`
- AFTER profile: `latest_after.csv`
- Custom profile: `latest_custom.csv`

These files are observational. They do not change movement, AI, puzzles, lives, or progression.

Rename/copy each snapshot after a run if you want to preserve multiple measurements.
