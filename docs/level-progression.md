# Signal Runner: Blackout — Facility Progression

## Surface — Cemetery Visitor Gate

**Purpose:** establish the missing-person case and preserve the original cemetery opening.

**Progression:** visitor terminal -> Cemetery Key -> far-right grave -> hidden staircase.

## R-1 — Underground Reception

**Narrative purpose:** proves the underground space was an organized facility, not a random basement.

**Gameplay:** search the desk, recover a 20A fuse, restore partial facility power.

**Connections:** Security (north), Archive (east, initially restricted), Supply Storage (west), Cemetery stairs (south).

## S-2 — Security Control

**Narrative purpose:** shows the facility had surveillance, access control, and deliberate containment procedures.

**Puzzle:** investigate a shift note and enter the scanner sequence `RED -> BLUE -> YELLOW -> BLUE`.

**Reward:** Security Keycard; facility signal 1/3.

**Failure consequence:** router resets and the alarm can attract the Clay Stalker.

## A-3 — Records Archive

**Narrative purpose:** identifies the missing individuals as facility intake subjects.

**Puzzle:** recover intake records, then use BLUE scanning on chemically erased shelf markings.

**Reward:** evidence exhibit + code `7-3-1`.

**Atmosphere:** dense shelving, old filing systems, optional documentation, deliberate safe-room pacing.

## L-4 — Medical Laboratory

**Narrative purpose:** establishes Project Resonance as a human experimentation program.

**Puzzle:** damaged audio log gives receiver order; calibrate A/B/C to BLUE / RED / YELLOW.

**Reward:** facility signal 2/3.

**Danger:** monster-enabled room with examination tables, blood evidence, and hiding locker.

## D-5 — Detention Block

**Narrative purpose:** confirms the four missing people were imprisoned underground.

**Puzzle chain:** YELLOW scanner bypass + archive code -> electronic lock bus -> physical Cell Key -> Cell 04 personal-effects bag.

**Reward:** evidence exhibit + Maintenance Badge.

## M-6 — Maintenance Tunnels

**Narrative purpose:** explains the power/signalling infrastructure that connects the facility.

**Puzzle chain:** locate screwdriver -> open Relay Panel 3 -> RED scanner alignment.

**Reward:** facility signal 3/3, unlocking Containment.

**Monster interaction:** a steam pipe can be struck to create a deliberate distraction.

## C-7 — Containment Wing

**Narrative purpose:** reveal the origin of the Clay Stalker / Subject C-17.

**Puzzle:** calibrate three separated containment nodes (YELLOW / BLUE / RED) while the monster becomes an active threat.

**Reward:** containment unlock + C-17 experiment log evidence.

## F-8 — Final Investigation

**Narrative purpose:** combine the investigation into a definite conclusion.

**Requirements:** intake records + Cell 04 personal effects + C-17 experiment log.

**Puzzle:** BLUE scan decrypts the evidence mirror; `E` uploads the case to Marshall PD.

**Ending:** the upload exposes Project Resonance, confirms three victims, identifies one survivor, identifies Subject C-17, and links Dr. Adrian Vale to the abductions/cover-up.

## Optional — Supply Storage

A safe optional room containing extra environmental notes and a damaged group photograph connecting all four missing people to the cemetery investigation.
